## Ultimate Loot Editor

Ultimate Loot Editor is an in raid loose loot editor for SPT. It lets you visualize loose loot spawn points, inspect what can spawn there, adjust spawn chances and item weights, and add or remove items.

The mod includes two editor UIs, which is changed in the F12 menu:

- Tarkov UI editor: Built from cloned Tarkov UI elements, then modified for loot editing while keeping the look and behavior close to the original in game UI.
- IMGUI editor: The base UI for users who prefer it.

## Features

- View loose loot spawn points in raid as world markers.
- Open a spawn point editor while standing and looking at a marker.
- Edit spawn chance.
- Add or remove possible loot items.
- Change individual item weights.
- Compare edited loot against vanilla loot.
- Revert a spawn point back to vanilla.
- Edit supported items such as weapons, armor, and helmets.
- Automatically handles compatible ammo for magazines/weapons when loot is generated.
- Saves map edits as JSON files that can be shared or manually edited.
- Supports modded items, weapons, armor, and helmets.
