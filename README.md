# Ultimate Loot Editor

Ultimate Loot Editor is an in-raid loose loot editor for SPT. It lets you visualize loose loot spawn points, inspect what can spawn there, adjust spawn chances and item weights, add or remove items, and create new spawn points.

The editor uses cloned in-game UI elements so it feels close to the native EFT interface instead of a separate debug menu.

## Installation

Extract the release zip into your SPT install folder.

After installing, these files should exist:

- `SPT_Runtime/user/mods/Ultimate Loot Editor/Ultimate Loot Editor.dll`
- `BepInEx/plugins/Ultimate Loot Editor/Ultimate Loot Editor.dll`

## Features

- View loose loot spawn points in raid as world markers.
- Open a native in game spawn point editor.
- Edit spawn chance.
- Add, remove, and search items to add.
- Change individual item spawn weights.
- Compare edited loot against the vanilla spawn point.
- Revert a spawn point back to vanilla.
- Create new loose loot spawn points.
- Name custom spawn points.
- Move and rotate new or edited spawn points.
- Preview an item at a spawn point before saving.
- Toggle gravity for a spawn point, useful for specific item placement.
- Copy spawn loot data from one spawn point and paste or replace it onto another.
- Edit supported items such as weapons, armor, and helmets.
- Automatically handles compatible ammo for magazines and weapons when loot spawns.
- Saves map edits as JSON files that can be shared or manually edited.
- Supports modded items, weapons, armor, and helmets.

## Basic Usage

- Press `F9` to toggle spawn point visualization.
- Look at or stand near a spawn sphere and press `Mouse 4` to open the editor.
- Press `Mouse 3` to create a new spawn point.
- Press `Ctrl+S` to save while the editor is open.
- Press `Ctrl+Z` / `Ctrl+Y` to undo or redo editor changes.
- Press `Ctrl+C` to copy the open spawn point's loot data.
- Press `Ctrl+V` to add copied loot data to the open spawn point.

These keybinds can be changed in the BepInEx F12 menu.

## New Spawn Placement

When placing a new spawn point:

- Arrow keys move it relative to your camera.
- `'` moves it up.
- `/` moves it down.
- `Q` and `E` rotate it.
- Hold `Shift` to move or rotate faster.
- Hold `Ctrl` to move or rotate slower.
- Press the open-editor key to open the new spawn point and add loot.

## Saving

ULE saves edits as JSON files under the server-side mod folder:

`SPT_Runtime/user/mods/Ultimate Loot Editor/maps`

These JSON files are the actual loot edits. They can be shared, backed up, or manually edited if needed.

## FIKA Compatibility

- **SPT/FIKA host:** Install the server-side ULE mod in `SPT_Runtime/user/mods`. This applies spawn and loot changes.
- **Playing FIKA/joining a host:** ULE does not need to be installed. Loot changes come from the host/server.
- **FIKA Headless client:** Do not install the ULE BepInEx plugin. Headless should only use the loot changes generated by the host/server.
- **Editing from a separate client:** Copy any generated ULE JSON edit files to the host/server's ULE map folder.
